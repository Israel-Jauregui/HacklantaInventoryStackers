# 🚧 StreetSense  
**AI-powered road issue reporting for smarter, safer cities**

---

## 📱 Overview  
StreetSense is a mobile app that allows users to quickly report road issues (like potholes) using their camera.

With **AI-powered detection**, **location tracking**, and **anonymous reporting**, StreetSense helps cities identify and fix infrastructure problems faster.

---

## ✨ Features  

### 📸 Snap & Detect  
- Capture potholes using your phone camera  
- AI analyzes:
  - Size  
  - Depth  
  - Severity  

### 📍 Smart Location  
- Automatic GPS detection  
- Options to:
  - Adjust location  
  - Type address  
  - Drop a pin  

### 🧠 AI Severity Scoring  
- Categorizes issues:
  - 🟢 Minor  
  - 🟡 Moderate  
  - 🔴 Critical  

### 📝 Report Customization  
- Add notes  
- Upload multiple photos  
- Toggle:
  - Anonymous reporting  
  - Fix notifications  

### 🗺️ Live Map View  
- View nearby reports  
- Filter by severity  
- Identify high-risk areas  

### 📤 City Submission  
- Reports sent to local authorities  
- Added to public infrastructure map  

---

## 🎯 Problem  
- Road issues are underreported  
- Reporting systems are slow and outdated  
- Cities lack real-time infrastructure data  

---

## 💡 Solution  
StreetSense provides:
- ⚡ Fast reporting (camera-first UX)  
- 🤖 Smart analysis (AI-powered)  
- 🌍 Real impact (direct reporting system)

## 🧪 How It Works  

1. Open the app  
2. Tap **+ Report**  
3. Capture pothole  
4. Confirm location  
5. Review AI analysis  
6. Submit report
